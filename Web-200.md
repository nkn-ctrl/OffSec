## Web Application Enumeration Methodology  
### Discovering Running Services  
    nmap -Pn $IP
    nmap -sV $IP
    nmap -p 80 --script http-methods $IP

### Banner Grabbing  
    curl -I http://$IP #headers only

### Automated HTTP Endpoint Discovery  
[Hakrawler](https://github.com/hakluke/hakrawler)  
    sudo apt install hakrawler  
    echo "http://enum-sandbox" | hakrawler -u  
[DIRB](https://dirb.sourceforge.net/)  
    dirb http://enum-sandbox
